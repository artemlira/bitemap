# WordPress як редакція статей

Рибомапа може показувати статті з WordPress поруч із власними. Next.js читає публічний
REST API на сервері, тож ключі й CORS не потрібні.

## Налаштування

1. Підніми WordPress (наприклад, на піддомені `cms.artemlira.com` у Hostinger) і переконайся, що
   працює `https://cms.artemlira.com/wp-json/wp/v2/posts`.
2. У змінних середовища Next.js задай `WORDPRESS_URL=https://cms.artemlira.com`.
3. Публікуй записи як звичайно. Перша рубрика запису стає категорією картки, заголовки `<h2>`
   в тексті стають змістом статті, а перше зображення й текст беруться з редактора.
4. Щоб нові записи з'являлись одразу (а не через 10 хвилин), задай `REVALIDATE_SECRET` і додай у
   WordPress вебхук «запис опубліковано» на `POST https://<сайт>/api/revalidate` із заголовком
   `x-revalidate-secret: <секрет>`.

## Як це працює

- `src/entities/fishing-article/model/wordpress.ts`: запити до REST API (кеш 10 хвилин, тег `wordpress`).
- Статті WordPress мають slug з префіксом `wp-`, тому не конфліктують із вбудованими.
- Контент проходить через DOMPurify на сторінці статті.
- Без `WORDPRESS_URL` нічого не змінюється.

## Що не зроблено

- Окремі переклади англійською (поки та сама стаття для обох мов). Для цього знадобиться Polylang
  або окремі поля.
- Каталог водойм і користувачі залишаються у Firebase, їх у WordPress переносити не планується.
