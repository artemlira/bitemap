# Firestore Security Rules для BiteMap

Профілі, обрані водойми та авторські водойми є приватними даними. Правила в
`/firestore.rules` дозволяють користувачу читати й змінювати лише документ з
власним Firebase `uid`, вкладені `favorites` та документи з `user-spots`, у
яких `ownerId` збігається з його Firebase `uid`.

Щоб застосувати їх у Firebase Console:

1. Відкрий **Firestore Database → Rules**.
2. Замінити стандартні правила вмістом файлу `firestore.rules`.
3. Натисни **Publish**.

Після першого входу BiteMap створить документ `users/{uid}` автоматично. Не
створюй його вручну в консолі.

Авторські водойми створюються у верхньорівневій колекції `user-spots`. Вони не
є частиною публічного каталогу: правила дозволяють лише запити з фільтром за
`ownerId`, а змінити `ownerId` під час редагування неможливо.

Коли додамо загальний каталог водойм у Firestore, правила для `spots` будуть
окремими: публічне читання та обмежений запис. Не відкривай зараз доступ до
всіх колекцій через `allow read, write: if true`.
