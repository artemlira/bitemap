# BiteMap

BiteMap — двомовна мапа та спільнота для рибалок і шанувальників відпочинку
біля води. Сервіс допомагає знаходити водойми, планувати виїзди, публікувати
власні локації, фото й звіти та обмінюватися досвідом.

## Можливості BiteMap

- **Пошук водойм.** Каталог поєднує перевірені локації та опубліковані водойми
  користувачів. Водойми можна шукати за назвою, областю й населеним пунктом та
  фільтрувати за регіоном, типом водойми й видами риби.
- **Мапа й маршрути.** Для кожної водойми доступні координати, карта та
  посилання для побудови маршруту в Google Maps. Під час створення або
  редагування водойми можна вибрати точку кліком по карті або визначити її за
  поточним місцезнаходженням пристрою.
- **Власні водойми.** Зареєстровані користувачі створюють приватні локації,
  редагують їх і публікують для спільноти. Дані про область, громаду та
  населений пункт можна вибирати зі списків; опис, назва та інші поля
  підтримують українську й англійську мови з українським fallback.
- **Погода й умови риболовлі.** Сторінка водойми показує поточну погоду та
  прогноз на сім днів. Погодні умови, температура й сезон формують орієнтовну
  оцінку активності риби; це підказка для планування, а не гарантія улову.
- **Фотографії.** Користувачі додають зображення до водойм, підписують їх
  двома мовами, а автори можуть замінювати та видаляти власні фото.
- **Звіти з виїздів.** Рибалки описують дату, враження, оцінку, улов, спосіб
  ловлі, наживку та активність риби. Автор може редагувати й видаляти свій звіт.
- **Спільнота.** Публічні профілі показують водойми й звіти учасників.
  Користувачі стежать одне за одним, переглядають стрічку оновлень, коментують
  звіти та ставлять реакції на звіти й фотографії.
- **Поради й статті.** Двомовна бібліотека містить матеріали про снасті,
  техніки ловлі, водойми та планування виїзду. Редактори працюють у WYSIWYG-
  редакторі з форматуванням, списками, посиланнями й зображеннями; час читання
  обчислюється автоматично.
- **Обране й теми оформлення.** Користувач зберігає цікаві водойми та обирає
  світлу або темну тему.
- **Безпека спільноти.** Доступ до приватних водойм і профільних даних
  контролюється правилами Firestore; для публікацій передбачені інструменти
  скарг, модерації та керування контентом.

## Технології

- **Next.js 16 App Router**, **React 19** і **TypeScript** — вебзастосунок,
  маршрутизація та серверні API-маршрути.
- **Feature-Sliced Design** — поділ коду на app, views, widgets, features,
  entities і shared.
- **Firebase Authentication** — вхід через Google та email/password;
  **Cloud Firestore** — профілі, водойми, звіти, коментарі, реакції, підписки,
  статті та правила доступу.
- **Cloudinary** — зберігання фотографій із серверно підписаним завантаженням.
- **Leaflet**, **React Leaflet** і **OpenStreetMap** — карти та вибір
  координат; Google Maps — побудова зовнішніх маршрутів.
- **Open-Meteo API** — прогноз погоди для координат водойми.
- **next-intl** — українська й англійська локалізації та локалізовані URL.
- **SCSS Modules** — стилі компонентів і адаптивні теми; **Tiptap** —
  редактор статей; **DOMPurify** — очищення форматованого HTML.

## Дорожня карта

Цільовий функціонал вище описує, яким BiteMap має бути для користувачів.
Стан запланованих робіт:

1. **Геолокація в формі водойми — виконано.** Кнопка «Використати моє
   місцезнаходження» запитує дозвіл браузера, підставляє координати та показує
   вибрану точку на карті. Якщо доступ заборонено або геолокація недоступна,
   можна вибрати координати вручну.
2. **Загальна інтерактивна мапа водойм — базову версію виконано.** Каталог і
   опубліковані водойми спільноти показуються на одній карті; маркери
   синхронізовані з пошуком і фільтрами, а з картки маркера можна перейти до
   сторінки водойми. Для водойм без координат залишається доступною картка у
   списку. Наступне покращення карти — групування близьких точок.
3. **Модерація контенту — наступний крок.** Додати скарги на водойми, фото, звіти й коментарі,
   а також адміністративний процес перегляду та приховування неприйнятного
   контенту.
4. **Багатші звіти про виїзд.** Дозволити додавати фото до звіту та структуровані
   дані улову, наприклад вагу, довжину, снасть і умови ловлі.
5. **Сповіщення.** Повідомляти про нові публікації учасників, на яких
   підписаний користувач, і про взаємодії з його матеріалами.
6. **Календар клювання.** Перевірити й удосконалити оцінку активності риби,
   чітко показуючи її методику та відмінність від гарантованого прогнозу.
7. **Передрелізна перевірка.** Додати автоматизовані сценарії для ключових
   шляхів користувача, перевірити адаптивність, доступи Firestore та модерацію.

## Локальний запуск

Потрібен Node.js та заповнений `.env.local`. Змінні середовища та налаштування
Firebase і Cloudinary описані в [`.env.example`](.env.example),
[`docs/firebase-setup.md`](docs/firebase-setup.md) і
[`docs/firestore-security.md`](docs/firestore-security.md).

```bash
npm install
npm run dev
```

Після запуску відкрий [http://localhost:3000](http://localhost:3000).

## Перевірки

```bash
npm run lint
npm run build
```
